## 📜 Official Server Rules

1.  **Professional Conduct:** CosmoWhisper is a tool for professionals. Maintain a high standard of respect.
2.  **No Key Sharing:** Never share API keys (Groq/OpenAI) or License Keys publicly.
3.  **App Integrity:** No discussion of bypasses, cracks, or unauthorized modifications.
4.  **Channel Hygiene:** Post technical issues in `#bug-reports` to keep `#general-chat` clean.
5.  **Data Privacy:** Avoid transcribing or sharing sensitive PII (Personally Identifiable Information) in channels.
