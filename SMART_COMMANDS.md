# CosmoWhisper Smart Commands - Windows Native

## 📝 Text Manipulation

| Say This | What Happens |
|----------|--------------|
| **"Select All"** | Selects all text (Ctrl+A) |
| **"Delete All"** or **"Clear All"** | Deletes everything in the field |
| **"Copy All"** or **"Copy That"** | Copies all text to clipboard |
| **"Cut All"** or **"Cut Everything"** | Cuts all text to clipboard |
| **"Paste"** or **"Paste That"** | Pastes from clipboard (Ctrl+V) |
| **"Undo"** or **"Undo That"** | Undoes last action (Ctrl+Z) |
| **"Redo"** or **"Redo That"** | Redoes last action (Ctrl+Y) |

## 🎨 Text Formatting

| Say This | What Happens |
|----------|--------------|
| **"Uppercase"** or **"All Caps"** | Converts selected text to UPPERCASE |
| **"Lowercase"** or **"All Lowercase"** | Converts selected text to lowercase |
| **"Title Case"** | Converts Selected Text To Title Case |

## 📅 Utility Commands

| Say This | What Happens |
|----------|--------------|
| **"Date"** or **"Insert Date"** | Types today's date |

| **"Mute"** | Toggles system mute |
